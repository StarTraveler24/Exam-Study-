# Chapter 8 — Risk and Return

**Exam weight: 5 questions / 15 points.**

## Topics identified from professor review and student's notes
- Expected return from probability-weighted outcomes
- Standard deviation of possible returns
- Coefficient of variation (CV = standard deviation / expected return)
- Sharpe ratio ((expected return − risk-free rate) / standard deviation)
- CAPM: required return = risk-free rate + beta × market risk premium
- Market risk premium = expected market return − risk-free rate
- Portfolio beta = sum of each investment weight × its beta
- Changes in market risk premium and resulting change in required return
- Distinguishing expected return and required return to judge under/overvaluation

## Reading traps
- **Market return** is not the same as **market risk premium**.
- 'Risk-free rate remains unchanged' does not mean it is needed when only calculating the CHANGE in required return due to a premium change.
- Beta is a measure of systematic risk, not the same as standard deviation.
- For a stock with similar risk assumptions, expected return > required return suggests undervaluation; expected return < required return suggests overvaluation.
