# Chapter 9 — Stocks and Their Valuation

**Exam weight: 5 questions / 19 points (largest share).**

## Core equations
- Next dividend: D1 = D0 × (1 + g)
- Gordon growth: P0 = D1 / (r_s − g), applicable to constant perpetual growth with r_s > g
- CAPM for required stock return: r_s = r_f + beta × (r_M − r_f)
- Dividend yield = D1 / P0
- Capital gains yield for constant growth = g
- Required total return = dividend yield + capital gains yield
- Constant-growth company valuation: operating value = FCF1 / (WACC − g)
- Common equity value = operating value + nonoperating assets − debt − preferred stock value
- Value per share = common equity value / outstanding common shares

## Nonconstant-growth dividend valuation
1. Project individual dividends in the initial growth period.
2. Determine the first dividend after growth stabilizes.
3. Compute the stock's terminal price at end of the nonconstant period, P_N = D_(N+1) / (r_s − g_stable).
4. Discount all early dividends AND the terminal price to today.
5. Add their present values.
